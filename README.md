# 机场配置修改工具

一个完全在浏览器本地运行的 YAML 编辑器，用来给单个或多个机场节点批量生成带代理 IP 出口的新节点。

## 工作原理

编辑器按 Mihomo 2026 年 5 月后的 `dialer-proxy` 语法生成配置。假设选择机场节点 `香港 01`，并填写一个 SOCKS5 出口，新节点会类似：

```yaml
- name: 香港 01 · 住宅出口
  type: socks5
  server: 203.0.113.8
  port: 1080
  username: user
  password: pass
  udp: true
  dialer-proxy: 香港 01
```

实际链路为：

```text
本机 → 香港 01（机场节点）→ 203.0.113.8（代理 IP）→ 目标网站
```

目标网站看到的是代理 IP 出口地址。新版语法不再创建 `type: relay` 策略组。

## 功能

- 导入、粘贴和校验完整 Mihomo YAML
- 按名称、协议、服务器搜索节点
- 单选或多选机场节点
- 以卡片形式管理 YAML 内联节点，支持点击选择、单个或批量删除
- 单节点直接改名；批量添加前后缀或执行名称查找替换，并自动同步策略组引用
- 拖拽卡片调整 YAML 节点顺序，或按名称、协议、服务器规则排序后写回文件
- 组合筛选协议、服务器、端口范围、UDP、TLS、已有出口链和已选状态，可对筛选结果一键全选
- 顶部提供独立“配置编辑”入口，可打开已经生成好的 YAML，在不影响出口生成工作区的情况下编辑节点
- 独立编辑器支持最多 60 步撤销/恢复、源码只读预览、复制以及下载编辑结果
- 独立编辑器增加“节点组管理”：策略组筛选、组内拖拽、上移下移、名称/协议/服务器/全局节点顺序排序
- 支持多个策略组批量应用排序规则、特殊项置顶或置底、重复引用清理和排序预览
- 策略组内部支持多选节点后整体拖拽、批量上移/下移/置顶/置底，并可只对已选节点排序
- 组内节点区域支持一列、两列和三列显示；窄屏自动回退为单列
- 节点卡片、策略组列表和组内节点均支持按住 Shift 点击进行连续区间选择
- 删除策略组时扫描关联的 `rules` / `sub-rules`，可逐条选择迁移到其他策略组；未迁移规则安全清理
- 删除策略组时，其他策略组中对它的嵌套引用也会同步迁移，避免留下无效名称
- 出口生成与配置编辑工作区双向打通：当前配置或生成结果可直接送入编辑器，编辑结果也可返回继续添加出口
- 两个工作区常驻保留各自状态；顶部普通切换不会覆盖内容，只有显式传递操作才替换目标配置
- 配置载入后自动进入全高紧凑工作区，隐藏介绍标题并合并文件栏与节点/节点组标签
- 策略组筛选和排序设置按需展开，左右列表占满剩余视口并独立滚动
- 提供专注模式覆盖整个窗口，可点击按钮或按 Esc 退出
- 节点改名会同步策略组及 `rules` / `sub-rules`；策略组改名会同步嵌套组引用及规则目标
- 删除节点会清理策略组引用和直接指向该节点的路由规则，避免导出带失效引用的配置
- 生成 SOCKS5 或 HTTP/HTTPS 出口节点
- 粘贴并自动识别代理网站常见的一键复制格式：`IP:PORT`、`IP:PORT:USER:PASS`、`USER:PASS@IP:PORT`、代理 URL、JSON、键值字段、表格与多行内容
- 可选用户名、密码、UDP、TLS 与证书验证设置
- 自定义节点命名模板
- 自动创建出口策略组
- 可把新出口同步到包含原节点的策略组
- 保留原 YAML 的字段、顺序和注释
- 复制或下载生成结果
- 所有内容仅在浏览器本地处理
- 选择任意本地文件生成局域网下载二维码，手机与电脑连接同一 Wi-Fi 后扫码下载
- 生成后的 YAML 可直接生成二维码，临时文件保留约 30 分钟，最大支持 50 MB

配置编辑工作区最多同时载入两个配置文件：单文件保持独立编辑；载入两个文件后，可使用左右分屏拖拽复制或选择主文件进行节点汇总。跨配置操作只复制节点，不删除来源文件中的节点，并会自动处理 `dialer-proxy` 依赖。

## 本地运行

Windows 可直接双击项目根目录的 `启动编辑器.cmd`，脚本会启动本地服务并自动打开浏览器。默认使用端口 4173；若被占用，会自动尝试 4174–4183。

二维码传文件需要保持启动窗口开启。首次使用时，如果 Windows 防火墙询问是否允许 Node.js 访问网络，请勾选“专用网络”；无需允许公用网络。

也可以通过命令行运行：

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

测试：

```bash
pnpm test
```

### 离线刷新已有节点

打开待更新的配置，点击「离线刷新」，选择一个或多个本地 .yaml / .yml 订阅文件（需含内联 `proxies`）。自动建议只匹配唯一同名且同协议的节点。预览会显示每条更新的来源；跨文件重名、改名或不同名称需要手动指定。可逐个勾选，也可按协议筛选后批量勾选。刷新时不下载安装订阅，不自动增删节点；保留原节点名称、策略组、规则和原有 `dialer-proxy`。取消不会改变配置；应用后可撤销，再按原流程下载 YAML。用不同文件区分同名节点时，请核对来源，即使只导入一份订阅也不能通过同名证明来源一致。
